# F5Web

[English](#english) | [中文](#chinese)

---

## English

**F5Web** is an Xposed module that leverages WebView and Chromium pseudo-protocols or injection methods to inject custom JavaScript scripts into **all WebViews** and **some Chromium-based** applications.

You can define your own scripts and have them automatically injected into the system WebView and Chromium kernel.  
In other words, any page loaded by apps that use the system WebView, or Chromium (without heavy modifications), can be injected with custom JS.

### Features
- Inject custom JavaScript into system WebView and Chromium-based browsers/apps
- Works with most apps that rely on the system WebView component
- Compatible with standard Chromium (non‑modified versions)
- Fully configurable via Xposed framework

## 中文

**F5Web** 是一个 Xposed 插件，利用 WebView 和 Chromium 的伪协议或注入方法，使所有 WebView 以及部分基于 Chromium 的应用能够注入自定义的 JavaScript 脚本。

你可以自定义脚本，并将其注入到系统 WebView 和 Chromium 内核中。  
换句话说，只要是使用了系统 WebView 的应用所加载的页面，或是没有经过魔改的 Chromium，都可以注入 JS。

### 功能特点
- 向系统 WebView 和基于 Chromium 的浏览器/应用中注入自定义 JS
- 适用于大部分依赖系统 WebView 组件的应用
- 兼容标准 Chromium（非魔改版本）
- 通过 Xposed 框架进行灵活配置
